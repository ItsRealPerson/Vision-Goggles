# Vision Goggles - Minecraft 1.20.1 (Branch: 1.20.1)

**Estado: Estable / Completado**

Esta versión del mod es compatible con Minecraft 1.20.1 utilizando Architectury.

## 🚀 Lo que funciona:
- **Todos los Modos de Visión**: Nocturna, Térmica, Biométrica e Hydro.
- **Estación de Modificación**: Instalación de módulos estable.
- **Accesorios**: Compatible con Curios (Forge) y Accessories/Trinkets (Fabric).
- **Zoom**: Sistema de zoom funcional.
- **HUD**: Interfaz de batería clásica.

## 🛠️ Requisitos:
- Java 17
- Fabric Loader / Forge
- Architectury API
- Cloth Config
- Accessories (Fabric) / Curios (Forge)
