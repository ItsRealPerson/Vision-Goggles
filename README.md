# Vision Goggles - Minecraft 1.20.4 (Branch: 1.20.4)

**Estado: Estable / Completado**

Esta versión del mod es compatible con Minecraft 1.20.4 utilizando Architectury.

## 🚀 Lo que funciona:
- **Todos los Modos de Visión**: Nocturna, Térmica, Biométrica e Hydro.
- **Estación de Modificación**: Funciona al 100% con instalación de módulos y mejoras.
- **Accesorios**: Compatible con Curios (NeoForge) y Accessories (Fabric).
- **Zoom**: Zoom dinámico y fluido.
- **HUD**: Interfaz de batería y modo de visión estable.

## 🛠️ Requisitos:
- Java 17
- Fabric Loader / NeoForge
- Architectury API
- Cloth Config
- Accessories (Fabric) / Curios (NeoForge)
