# Vision Goggles - Minecraft 1.20.4 (Stable)

**Branch Status: Complete / Maintenance**

This version of Vision Goggles is fully functional and stable for Minecraft 1.20.4, built using the Architectury API for seamless cross-platform support.

## 🌟 Key Features
- **Four Vision Modes**:
  - **Night Vision**: High-clarity illumination in pitch black.
  - **Thermal**: Highlights living entities through walls and identifies heat sources.
  - **Hydro**: Crystal clear vision underwater.
  - **Biometric**: Scans and displays health/distance data of targets.
- **Modular System**: Upgrade your goggles with custom modules using the **Modification Station**.
- **Battery System**: All effects consume energy. Recharge using batteries or external power modules.
- **Dynamic HUD**: Real-time battery indicator and mode status displayed on your screen.
- **Smooth Zoom**: High-precision zoom functionality for tactical scouting.

## 🛠️ Requirements
- **Java**: 17
- **Fabric**: Fabric Loader & Fabric API
- **NeoForge**: Compatible NeoForge build
- **Dependencies**: 
  - Architectury API
  - Cloth Config
  - Accessories (Fabric) / Curios (NeoForge)

## 📦 Compatibility
- **Curios API**: Fully supported for the `Eyes` slot.
- **Accessories API**: Fully supported for the `Face` slot.
- **Sodium/Iris**: Optimized shaders for maximum performance and compatibility.

## 🎮 How to use
1. **Toggle**: Press `N` to activate/deactivate your goggles.
2. **Switch Mode**: Press `M` to cycle through installed vision modules.
3. **Zoom**: Hold `V` to zoom in (requires zoom module).
4. **Recharge**: Shift + Right-click with a battery while wearing the goggles.
